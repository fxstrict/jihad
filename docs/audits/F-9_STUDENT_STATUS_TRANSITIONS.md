# F-9 — انتقالات حالة الطالب: Phase 1 مقابل `canTransitionStudent`

**الحالة: غير محسوم — بانتظار قرار مالك المنتج.** لم تُعدَّل قواعد المجال ولا الاختبارات في هذه الشريحة. التاريخ: 2026-10-29.

## المصادر
- **Phase 1 §C.6:** `Student: active ⇄ paused → graduated → archived`.
- **Phase 1 §A.1 (Student، Life):** `Active↔Paused→Graduated→Archived→Deleted`.
- **Phase 1 §4.4 (قاعدة عامة لكل الكيانات):** `Active → Archived → Deleted(Tombstone) → Purged` — الأرشفة عبر `status`.
- **الكود:** `packages/domain/src/rules/studentRules.ts` → جدول `ALLOWED` (التعليق فيه: «الأرشفة متاحة من أي حالة»).

## جدول المقارنة (كل الأزواج المرتبة المختلفة)

| من ← إلى | Phase 1 (§C.6 / §A.1) | الكود الحالي | الحكم |
|---|---|---|---|
| active → paused | مسموح | مسموح | ✅ متطابق |
| paused → active | مسموح (⇄) | مسموح | ✅ متطابق |
| paused → graduated | مسموح | مسموح | ✅ متطابق |
| graduated → archived | مسموح | مسموح | ✅ متطابق |
| graduated → paused | غير مذكور | ممنوع | ✅ متطابق |
| archived → paused | غير مذكور | ممنوع | ✅ متطابق |
| archived → graduated | غير مذكور | ممنوع | ✅ متطابق |
| **active → graduated** | غير مذكور (السلسلة تمر عبر paused) | **مسموح** | ⚠️ الكود أوسع |
| **graduated → active** | غير مذكور (لا رجوع بعد graduated) | **مسموح** | ⚠️ الكود أوسع |
| **archived → active** | غير مذكور (السلسلة أحادية الاتجاه) | **مسموح** | ⚠️ الكود أوسع (الاستعادة في §D.6 تخص `deletedAt` لا `status`) |
| **active → archived** | غير مذكور في §C.6؛ لكن §4.4 العام يسمح `Active→Archived` | **مسموح** | ❓ غموض داخل Phase 1 نفسه |
| **paused → archived** | غير مذكور في §C.6؛ §4.4 العام يسمح بالأرشفة | **مسموح** | ❓ غموض داخل Phase 1 نفسه |

الخلاصة: 7 أزواج متطابقة، **3 أزواج الكود فيها أوسع من Phase 1**، و**2 غامضان** (§C.6 يقول سلسلة، §4.4 يسمح بالأرشفة العامة).

## التوصية
**الحفاظ على Phase 1 كما هو** ما لم يصدر قرار رسمي بتعديله، أي:
1. لا يُعتمد توسيع §C.6 ضمنيًا من الكود.
2. عند أول Use Case يستهلك `canTransitionStudent` (شريحة S4: `ArchiveStudent`/تغيير الحالة) يجب أن يكون القرار قد صدر.
3. حتى صدور القرار: الاختبارات الحالية تثبّت السلوك الموجود ووُسمت F-9؛ ولا يُبنى عليها واجهة تعتمد الأزواج الستة المختلفة.
